## 🧩 About

**Terraria Config** is a comprehensive configuration tool for Terraria 1.4.4 featuring overlay menu, GUI, hotkey toggles, real-time settings, and profile manager.

Based on popular tools like **Terraria Overhaul**, **TModLoader**, and **Hero's Mod**.

## ✨ Features

### 🎮 Core Settings
- Overlay Menu — in-game configurable menu
- Hotkey Toggles — bind keys for quick settings
- Real-time Settings — apply changes without restart
- Profile Manager — save and load multiple configurations

### 🎨 Interface & Display
- GUI Customization — change colors, fonts, and layout
- HUD Editor — move and resize elements
- Tooltip Enhancements — show detailed item info

### 🏋️ Utility & Performance
- Performance Monitor — display FPS and memory usage
- Auto-save Config — backup settings automatically
